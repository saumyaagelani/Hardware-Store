# Shopify theme assets (not deployed by Render)

This branch only holds files that Shopify downloads by URL:

- `theme/` — the "Render look" files for the Shopify theme copy **Horizon – Render look**
  (dark Northline palette, Satoshi font, prototype-style header, homepage, footer, product cards,
  collection/search pages, quote + contractor forms, square-footage calculator).
- `product-art/` — the prototype's product illustrations as JPG photos, used as product images
  for the 59 products that had no photo.

The working branch and the Render demo are unaffected. Safe to delete once the store has real photos.
